# EmberPad AppIcon sources (EP-19)

Original artwork: Ember red field, white worksheet with folded corner,
Ember red title bar, three taupe rules, dark-slate pen diagonal.
No stock, no downloads, no GoodNotes reference.

- `AppIcon.source.svg` — the vector authority (1024 box).
- `generate-appicon.py` — raster exporter (needs Pillow, already used for
  local regeneration): `python3 generate-appicon.py` writes
  `../Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`.
